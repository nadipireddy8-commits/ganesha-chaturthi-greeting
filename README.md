- index.html

- images/ganesha-1.png

## Features
- Lord Ganesha hero image
- Divine golden aura
- Animated diyas
- Falling petals
- Golden particles
- Fireworks celebration
- Rangoli animation
- 3D mouse parallax
- Telugu devotional music
- Music ON/OFF control
- Share Wishes button
- Three-image Ganesha gallery
- Personal signature: N R JITENDAR REDDY
- Responsive mobile layout

The uploaded Telugu Ganesha music starts when the visitor clicks
"Begin Celebration", which is a user gesture and therefore works better
with browser autoplay restrictions.
